# Header
The header options change due to the user roles. Regardless of the role, the profile page of the user and the logout button can be found on the right side.

# Footer
Regardless of the role, the footer is consistent across the platform, offering links to the 'Privacy Policy' and 'Imprint' of the project, which reveal the project's privacy practices and legal disclosures, respectively.

# Profile
The 'Profile' section displays all your personal information. 

**Modify Username** \
You can modify your username by entering the username in the textfield. 

**Change password** \
Your password can be changed by entering your old password and then enter a new password twice. By clicking on 'Safe Changes' you confirm your changes.<br><br>

# Student Role Functionalities
**Header Navigation Options**\
As a student, the header presents two primary navigation options:
- 'My Enrollments'
- 'All Classrooms'

## My Enrollments
The 'My Enrollments' section displays a list of classrooms you're already enrolled in. 
The 'Visit Classroom' button redirects you to the 'Classroom' page where you have an overview of the classroom and its projects. The 'Enroll' button redirects you to the 'All Classrooms' page where you can enroll in all existing classrooms.<br><br>

<img src="https://github.com/U2Vj/turtl/assets/12676587/929800f7-24c9-4c0d-ac59-bde763ea4c95" alt="TURTL My Enrollments" width="700">


## All Classrooms
The 'All Classroom' section displays a list of all existing classrooms. You can search for a classroom and either enroll in a classroom by clicking on 'Enroll' or you can visit an already enrolled classroom by clicking on 'Visit'. In both cases, you are then directed to the respective 'Classroom' page.<br><br>

<img src="https://github.com/U2Vj/turtl/assets/12676587/8542cb0e-6e87-4022-bf00-5def4afc3a62" alt="TURTL All Classrooms" width="700">


## Classroom
**Projects** \
The 'Projects' section displays all the containing projects within the respective classroom. To solve a task within a project, you can click on the linked task buttons. This directs you to the respective 'Task' page. 

**Information** \
The 'Information' section displays all the containing informations within the respective classroom. You can visit the 'Helpful Resources' by clicking on the links. This directs you to the respective website. You can also unenroll from the classroom by using the 'Unenroll' button.<br><br>

# Instructor Role Functionalities
Instructors have all the capabilities of a student. The additional functionalities are shown below.

**Header Navigation Options** \
As an instructor, the header presents three primary navigation options:
- 'My Classrooms'
- 'My Enrollments'
- 'Invite Users'

## My Classrooms
The 'My Classrooms' section displays a list of classrooms you've created. The 'Edit Classroom' button redirects you to the 'Edit Classroom' page where further details of the classroom can be modified. The 'Create' button opens a modal in which you can create a new classroom by entering a new classroom title.<br><br>

<img src="https://github.com/U2Vj/turtl/assets/12676587/28ea6bb8-2bf8-4c1d-89eb-5fc926b90f83" alt="TURTL My Classrooms" width="700">


## Edit Classroom
The 'Edit Classroom' section allows you to modify the whole classroom. You can change the classroom title by entering a new classroom title and then click on 'Safe Title'. 

**Projects** \
The 'Project' section shows all your existing projects. You can create a new project with the use of the 'Add Project' button by entering a new project name. By clicking on 'Show More' all details of the project are displayed. You can change the project title by entering a new project title and then click on 'Safe Title'. By clicking on 'Delete Project' you can delete the project after confirming it in the modal. \
You can also add a task for the project with the use of the 'Add Task' button. In the modal that opens you can enter the task title, description, difficulty level and task type. Then you are directed to the 'Edit Task' page. <br><br>

<img src="https://github.com/U2Vj/turtl/assets/12676587/ae263820-03d1-4168-9421-b49335bfde49" alt="TURTL Edit Classroom with Projects" width="700">


**Settings** \
In the 'Settings' section you can add helpful resources by clicking on 'Add Resource'. In the modal that opens you can enter the title and the URL to the desired website and confirm the creation of the helpful resource with the use of the 'Create' button.\
You can delete the classroom after confirming it in the modal by clicking on 'Delete Classroom'.<br><br>

<img src="https://github.com/U2Vj/turtl/assets/12676587/b87ea2e4-596f-40c4-85e4-7585bd2c35bd" alt="TURTL Edit Classroom with Settings" width="700">


**Instructors** \
The 'Instructors' section displays a list of all instructors of the classroom. If you click on the trash can button, you can remove the instructor from the classroom. At least one instructor has to stay in the classroom. If you want to remove yourself out of the classroom, you have to confirm it in the modal that opens. \
You can add or also delete a new instructor to the classroom by clicking on 'Add Instructors'. This opens a modal with a list of all existing instructors. By clicking on the '+' button you can add the respective instructor to the classroom.<br><br>

<img src="https://github.com/U2Vj/turtl/assets/12676587/a2f5b879-def2-4728-808e-e16eca63e0d2" alt="TURTL Edit Classroom with Instructors" width="700">


**Students** \
The 'Student' section displays a list of all students enrolled in the classroom.<br><br>

<img src="https://github.com/U2Vj/turtl/assets/12676587/a45a3440-79be-4f72-a967-f9eaa82fac77" alt="TURTL Enrolled Students" width="700">


## Manage Invitations
TURTL features an email invitation system: Instructors can invite students and administrators can invite students and instructors. In the 'Manage Invitations' sections you can click on the 'Invite User' button to invite new students. This directs you to the 'Invite Users' page. Next to each invitation, there is a renew button. This triggers an email to be sent to the invited user with a new invitation link. Any old links then become invalid. There also is a delete button which revokes the invitation.

**My Open Invitations** \
The 'My Open Invitations' section displays all your own open invitations.

**All Open Invitations** \
The 'All Open Invitations' section displays all open invitations.

## Invite Users
In the 'Invite Users' section you can invite either a single student or multiple students by entering their email addresses and then confirming your entry by clicking on 'Invite'.<br><br>

# Admin Role Functionalities
Administrators have all the capabilities of an instructor. The additional functionalities are shown below. \

**Header Navigation Options** \
As an Administrator, the header presents three primary navigation options:
- 'My Classrooms'
- 'My Enrollments'
- 'Invite Users'

## My Classrooms
**Classroom Editing Privileges** \
Administrators have the authority to edit any classroom within the system, regardless of whether they created it or are listed as an instructor. To manage other classrooms, Administrators can use the link located beneath the classroom cards to get directed to the required 'Classrooms' page.

## Invite Users
In the 'Invite Users' section administrators have the authority to also invite a single instructor by entering the email address and then confirming the entry by clicking on 'Invite'.

## Django Admin panel
An administrator can assign roles in the Django Admin Panel. The Django Admin Panel can be accessed via the backend URL plus `/django-admin/`, e.g. for development purposes `http://localhost:8000/django-admin/`.
